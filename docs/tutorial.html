MASON · Getting started

Build atomistic structures for first-principles calculations in natural language. This page opens on the first launch only; it stays in the docs/ folder of the installation.

Step 1 · Configure a model in the terminal

MASON has no built-in language model. On the first launch a wizard in the terminal asks which model to use, sends one test request to it and prints the answer. It then asks for an optional Materials Project key and for the folder that will hold your structures (default ~/Documents/MASON). The configuration and the keys are kept in the per-user configuration folder (macOS ~/Library/Application Support/MASON, Windows %APPDATA%\MASON, Linux ~/.config/MASON).

  1. 1–6OpenAI, Anthropic, Google, xAI, Mistral, DeepSeek: API key, then a model from the list (or any model id typed by hand).
  2. 7–10Alibaba (Qwen), Moonshot (Kimi), Zhipu (GLM), MiniMax: choose the China or the international endpoint, then the key and the model.
  3. 11–12ByteDance Volcengine (Doubao) and OpenRouter (one key for models of many vendors).
  4. 13Ollama: run ollama pull qwen3.6:27b first, then enter the model name. Models of 27B parameters or more with a 64k context are recommended.
  5. 14Configure later in the web interface.

Non-thinking models (deepseek-flash, gpt-5.6, claude-sonnet-5, gemini-3.8-flash, qwen3.8-flash, glm-5.3-flash) build a structure in seconds; long-thinking models take minutes per structure.

The wizard then asks for an optional Materials Project API key (free at next-materialsproject.org/api). It enables the two database tools that look up known crystals online; the wizard tests it with one query. Press Enter to skip.

To change the model, run MASON --setup. To check that the configured model answers, run MASON --test. To see the current configuration, run MASON --config.

Step 2 · The workbench

  • The terminal prints the addresses and the browser opens the workbench (by default http://127.0.0.1:4096/workbench; if the port is taken, the next free one is used): the conversation on the left, the structure viewer on the right. The MASON agent and your model are preselected under the input box. If the page shows "Add project" instead, use the full URL printed in the terminal.
  • Every structure the agent builds comes with a link; clicking it shows the structure in the viewer pane, where it can be rotated, zoomed and inspected atom by atom. Selection pages for interface candidates or atoms open in the same pane.
  • All files are written to the workspace folder you chose; sample structures are in its examples/ subfolder. Every structure the agent renders appears in the viewer pane automatically.

Step 3 · Try three requests

Read examples/si_bulk.vasp and report its space group and inequivalent sites.
From examples/pt_bulk.vasp cut a Pt(111) slab with 4 atomic layers and 15 Å vacuum,
fix the bottom two layers, save it as pt111_4l.vasp and render it.
Using pt111_4l.vasp, expand to a 3×3 surface cell, list the adsorption sites,
put CO (C end down, 2.0 Å) on the fcc hollow, keep 15 Å vacuum, check the geometry and render it.

Say what you want (orientation, layers, vacuum, site, thresholds); no tool names are needed. The agent reads, builds, validates and renders, and ends with a summary of the files and the key numbers.

What MASON can build

  • Reading and analysis: format conversion, space group and inequivalent sites, geometry validation, rendering
  • Bulk and molecules: supercells, vacancies, substitutions, interstitials, molecules, stacking faults, grain boundaries
  • Surfaces and 2D: slabs, bottom capping, frozen layers, vacuum, adsorption sites and adsorbates, passivation, reconstruction, nanoribbons, nanotubes, twisted bilayers
  • Interfaces and stacking: lattice-matching candidates with an interactive selection page, interface construction, solvent layers, stacking

If something goes wrong

  • The model returns 401 or 403: check the API key (and, for providers with two endpoints, that the key belongs to the endpoint chosen); MASON --test shows the exact error, MASON --setup lets you enter them again.
  • Port in use: MASON moves to the next free port and prints the address; MASON --port 5000 chooses a different preferred port.
  • Interface matching of a large system times out: raise mcp.structure.timeout in opencode.json.
  • More in docs/README.md of the installation.
